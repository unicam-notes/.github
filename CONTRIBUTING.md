# Come contribuire

Italiano · [English](i18n/en/CONTRIBUTING.md)

Studenti e tutor possono condividere appunti PDF, archivi ZIP con cartelle o materiali, esercitazioni, soluzioni, documenti Markdown e altri file pertinenti al corso.

## Dove contribuire

Segnala errori e correzioni tramite **Issues nel repository del corso interessato**, indicando il file o link, il problema e, se possibile, la correzione suggerita. Non serve un modulo dedicato.


Le pull request devono essere aperte nel repository del corso interessato. Le Discussions devono essere aperte esclusivamente nello [spazio centralizzato di `unicam-notes/.github`](https://github.com/unicam-notes/.github/discussions).

## Scegli come contribuire

- **Q&A**: domande e discussioni generali su corsi, esercizi o materiali, comprese idee e richieste di chiarimento.
- **Contribution**: nuovi materiali. Indica corso o modulo, descrivi il contenuto e aggiungi allegati o link.
- **Issues nel repository del corso**: errori nei materiali esistenti. Indica il file o il link e descrivi l’errore; se puoi, suggerisci una correzione.

Usa lo [spazio Discussions centralizzato](https://github.com/unicam-notes/.github/discussions) per tutti i corsi e indica il corso o il repository interessato. Le pull request vanno nei repository dei corsi; i materiali possono essere proposti anche come allegati nelle Discussions centrali. I due moduli attivi hanno etichette e istruzioni in italiano e inglese: puoi compilarli in entrambe le lingue. Il titolo si inserisce nel campo nativo di GitHub.

GitHub accetta allegati solo nei formati e nei limiti supportati dalla piattaforma: non tutti i PDF o ZIP sono necessariamente caricabili. Se un allegato non è accettato, condividi un link accessibile o proponi una pull request per aggiungere i file al repository. Un link non sostituisce il permesso di distribuire il materiale.

## Condividere file in un messaggio

Per condividere materiali, apri **New discussion → Contribution**, inserisci un titolo e scrivi il messaggio indicando il corso. Trascina i file supportati direttamente nel messaggio, incolla immagini oppure aggiungi link. Non è necessaria una pull request per proporre materiali tramite Discussion; gli allegati non vengono aggiunti automaticamente al repository del corso.

## Pull request

1. Apri il repository del corso e crea un fork, se necessario.
2. Aggiungi o modifica i file nella cartella pertinente, seguendo la struttura e le convenzioni già presenti. Usa nomi descrittivi ed evita duplicati o riorganizzazioni non necessarie. Puoi usare l’editor e il caricamento file di GitHub.
3. Apri una pull request con una breve descrizione del contributo, indicando autore originale e fonte nel materiale o in un README vicino ai file. I maintainer la esamineranno.

## Autori, diritti e licenza

Condividi soltanto materiale tuo o che hai il diritto o l’autorizzazione di distribuire. Cita sempre l’autore originale quando noto e la fonte, con un link se disponibile; conserva firme, crediti, provenienza e avvisi di copyright. Non pubblicare dati personali senza consenso.

Tutti i repository di UNICAM Notes adottano la [BSD 3-Clause](LICENSE). Ogni contributo deve rispettarne i termini; inviando materiali originali, accetti di renderli disponibili con questa licenza. Per i contenuti a cui si applica, conserva copyright, condizioni e disclaimer nelle distribuzioni del sorgente; nelle distribuzioni binarie riproducili nella documentazione o negli altri materiali forniti. Non usare i nomi del titolare o dei collaboratori per promuovere prodotti derivati senza autorizzazione scritta.

Controlla la licenza del repository del corso e dei singoli materiali. Il caricamento non rende automaticamente BSD 3-Clause i contenuti di terzi e non concede diritti mancanti.
